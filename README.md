# Fragrânciapura

E-commerce de perfumes em desenvolvimento com **Next.js + TypeScript**.

O projeto tem como objetivo digitalizar a operação da Fragrânciapura, reunindo catálogo de produtos, busca e filtros, carrinho, autenticação, checkout e gerenciamento de pedidos em uma aplicação web.

## Status

🚧 Em desenvolvimento

## Stack planejada

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Hook Form
- Zod
- Zustand
- PostgreSQL
- Prisma

## Funcionalidades planejadas

- Catálogo de perfumes
- Página individual de produto
- Busca por produtos
- Filtros por marca, gênero e preço
- Carrinho de compras
- Favoritos
- Autenticação
- Checkout
- Histórico de pedidos
- Painel administrativo
- Gerenciamento de produtos e estoque
